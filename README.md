# Genesis by Atexar

A static B2B website retaining Atexar’s dark-and-lime design, oversized typography, chrome sculpture and original section layout.

## Content

Genesis brings together SaaS Marketing, Sales Boosting, Autonomous Virtual Assistance, and Unified Intelligence. Copy describes the intended offering without invented performance statistics or client testimonials.

The founder note features Vedansh Dubey’s supplied portrait in a circular, monochrome frame near the bottom right. The motto is: “Think boldly. Build relentlessly. Make progress inevitable.” The original photo bytes are preserved; cropping and toning are applied with CSS.

## Deploy on Cloudflare Pages

Upload this ZIP through Pages Direct Upload, or extract it and upload the directory containing index.html. No framework, dependency installation or build command is required. Keep the assets directory alongside index.html.

After deployment, attach atexar.in through the project’s custom-domain settings. Preserve existing email DNS records.

## Contact

Enquiries open the visitor’s email app addressed to Vedanshdubey@atexar.in, with a Genesis enquiry subject. This site does not include a backend contact form.

## Animation and accessibility

Includes a pointer-responsive chrome sculpture, ticker, section reveals, animated visual cards, signal pulse, rotating portrait accent, disclosure transitions and reading-progress indicator. Pause motion freezes ambient motion and reveals content. Operating-system reduced-motion preferences are respected. Native disclosure controls and navigation support keyboard access.

Fonts load from Google Fonts with local system fallbacks. All other assets are included.

## Validation

JavaScript syntax, local asset references, unique HTML IDs and anchor targets were checked. Browser layout verification could not run because the available Chromium download failed. Review the deployed site on desktop and mobile before launch.
